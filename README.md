# 친구무스메 더비

친구 사진과 이름을 넣고 구경만 하는 운빨 경마 룰렛. 서버 없이 정적 파일만으로 동작합니다.

## 구조

- `index.html` — 화면 구조
- `css/style.css` — 스타일
- `js/game.js` — 레이스 시뮬레이션, 스킬, 렌더링

## 로컬에서 열기

`index.html`을 브라우저에서 바로 열면 됩니다.

## GitHub Pages 배포

1. 이 폴더 전체를 저장소에 올립니다.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 에서 열립니다.

## 사용법

- **이름 한 번에 넣기**: 명단 섹션의 텍스트 박스에 이름을 줄바꿈(또는 쉼표)으로 붙여넣고 "한 번에 추가". 사진·대사는 카드의 편집에서 나중에.
- **당첨 방식**: 1등 당첨 / 꼴등 당첨.
- **전체 화면**: `⛶ 전체 화면` 버튼 또는 `F` 키. 마우스를 움직이면 컨트롤이 잠깐 나타나요. `Esc`로 해제.
- **스페이스**: 출발.

## 결승 연출

당첨 경계(1등 모드: 1위/2위, 꼴등 모드: 꼴찌/뒤에서 둘째)가 결승선 70m 안에 들어오면 접전 정도에 따라 슬로우가 걸려요.
3m 이내 박빙이면 0.18배, 8m 이내 0.3배, 15m 이내 0.45배, 그 이상이면 0.65배. 슬로우 중에는 배속(x2/x4) 설정을 무시해요. 카메라는 결승선으로 줌인하고 캐릭터가 커져요. 결정 순간엔 0.45초 정지(히트스톱).
꼴등 모드에서는 앞사람들 골인을 1.6배로 빠르게 넘기고, 마지막 둘에 카메라를 붙여요. 한 명만 남으면 스포트라이트.

## 조정하기 (`js/game.js`)

- 슬로우 트리거 거리와 배율: `TRIGGER_M`, `updateDrama()`

- 스킬 목록과 발동 확률: `POOL` 배열
- 역전각 확률(35%)과 선두 휘청 확률(12%): `buildRace()` 안의 `events`
- 응원 보정 세기: `step()` 안의 "관중 응원 보정" 부분
- 공정성 확인: 브라우저 콘솔에서 `__fdFairness(1000)`

사진과 전적은 각 브라우저의 localStorage에만 저장됩니다.
